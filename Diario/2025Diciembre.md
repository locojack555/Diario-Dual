# DICIEMBRE

## Semana 1 - 5 de diciembre

Durante esta semana me centré en estudiar la base de datos del BIIT para entender bien dónde está cada cosa y cómo se relacionan las tablas. Esto era importante para luego poder hacer correctamente las consultas que necesitaré en los controladores del programa.

Además, también aproveché para ir mejorando un poco la parte visual del proyecto, haciendo algo de CSS para que la aplicación tuviera mejor aspecto y fuera más agradable de usar.

---

## Semana 8 - 12 de diciembre

Esta semana mi tutor aún no había replicado la base de datos en nuestro servidor, así que trabajé directamente sobre la base original para ir adelantando trabajo.

Me puse a preparar las consultas necesarias para los controladores, probándolas y guardándolas en un bloc de notas para tenerlas organizadas y listas para cuando ya tuviéramos todo montado.

También seguí mejorando el CSS de la aplicación, intentando que todo fuera más claro y ordenado de cara al usuario.

---

## Semana 15 - 23 de diciembre

Durante esta semana seguí trabajando con la base de datos y mi tutor ya duplicó las tres primeras tablas, que eran las de usuarios. Gracias a esto, ya pude empezar a hacer una parte funcional del programa.

Implementé una vista donde se carga la lista de usuarios desde la base de datos, lo que ya me permitió ver algo real funcionando dentro de la aplicación.

Además, añadí funcionalidades como la paginación de tablas, filtros y ordenación, para mejorar la usabilidad y hacer que el manejo de datos fuera más cómodo.
